* **Manifest Short Description:**

### Short Name

* **Short Name:**

### Store Listing Description

* **Store Listing Description:**
* Write a clean, professional, medium-length description.
* Clearly explain what the extension does, its main benefits, and who it is for.
* Make the content useful and natural rather than artificially optimized.
* Use SEO naturally without keyword stuffing or repetitive phrases.

### Single-Purpose Description

* **Single-Purpose Description:**
* Clearly describe the extension's single purpose.
* Each single-purpose description must be **1000 characters maximum**.
* Keep the wording precise and directly connected to the extension's actual functionality.

### Permission Justification

* **Permission Justification:**
* Provide a clear justification for **each permission declared in the extension's Manifest**.
* Explain why the extension needs each permission and how it is used.
* Do not request or justify permissions that are unnecessary for the extension's actual functionality.
* Keep the explanations transparent, specific, and suitable for Chrome Web Store review.

## Privacy Policy

Create a complete **Privacy Policy specifically for the Chrome extension**.

The privacy policy must:

* Focus on **Chrome Web Store privacy and compliance requirements**.
* Clearly explain what data the extension accesses, collects, processes, stores, or transmits, where applicable.
* Explain the purpose of any data access.
* Explain whether data is stored locally, remotely, or both.
* Explain any third-party services or APIs used by the extension, if applicable.
* Clearly state whether user data is sold, transferred, or used for advertising, if applicable.
* Follow the extension's actual Manifest permissions and functionality.
* Use clear, transparent language suitable for users and Chrome Web Store reviewers.
* Do not make unsupported privacy claims.
* Do not claim that data is never collected, stored, or transmitted unless that is actually true.
* Make the policy comprehensive enough for Chrome Web Store compliance while remaining easy for users to understand.

## SEO & Copywriting Requirements

Approach this as a **Senior Copywriter and SEO Specialist**.

The listing should:

* Be professionally written.
* Be naturally optimized for relevant search terms.
* Use keywords strategically without over-optimization.
* Avoid keyword stuffing.
* Avoid repetitive or unnatural wording.
* Avoid exaggerated or unsupported claims.
* Focus on the extension's real features, benefits, use cases, and target users.
* Provide genuine SEO value while remaining natural and readable.
* Be written specifically for the Chrome Web Store rather than as generic marketing copy.

Understand the extension's actual functionality before generating the content.

Generate **all required listing and SEO metadata** based on the extension and its Manifest.

The final content must be:

* Clean
